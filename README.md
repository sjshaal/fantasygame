# Potion & Prophecy 🧪

A browser-based fantasy potion-brewing game. Gather ingredients from the shelf, combine them in the cauldron, and discover recipes as you brew — with your discoveries tracked in an in-game journal.

## Features

- **The Cauldron** — combine ingredients to brew potions
- **Ingredient Shelf** — collect and manage the components you brew with
- **Recipe Book** — known recipes are recorded as you discover them
- **The Journal** — a running log of your ingredients, potions, and progress
- Animated, mood-tinted video backdrops and cauldron/glow effects for atmosphere

## Running locally

This is a static single-page app — no build step required.

```bash
open index.html
```

Or serve it locally:

```bash
npx serve .
```

## Tech

- Vanilla HTML/CSS/JS
- [Tailwind CSS](https://tailwindcss.com/) (via CDN)
- Google Fonts (Cinzel, Lora)
